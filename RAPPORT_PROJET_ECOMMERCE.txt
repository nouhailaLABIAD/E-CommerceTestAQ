1.1. OBJECTIF ET DOMAINE METIER
--------------------------------
L'application est une plateforme e-commerce destinee a une patisserie en ligne.
Elle permet :
  - La consultation de produits (patisseries) par les visiteurs
  - L'authentification et l'inscription des clients
  - La gestion d'un panier d'achat (ajout, modification, suppression)
  - Le passage de commandes avec gestion du stock
  - L'administration des produits, categories et commandes (role ADMIN)
  - Le telechargement et la gestion d'images pour produits et categories

1.2. ARCHITECTURE GENERALE
---------------------------
Le projet suit une architecture en couches (Layered Architecture) basee sur le
pattern MVC (Model-View-Controller), typique des applications Spring Boot :

    +---------------------+
    |   COUCHE PRESENTATION  |  <- Controllers Thymeleaf + Templates HTML
    +---------------------+
              |
    +---------------------+
    |   COUCHE METIER (Service) |  <- Logique metier, transactions
    +---------------------+
              |
    +---------------------+
    |   COUCHE ACCES DONNEES   |  <- Repositories Spring Data JPA
    +---------------------+
              |
    +---------------------+
    |   COUCHE ENTITES / DTO   |  <- Modele de donnees (JPA Entities)
    +---------------------+

1.4. MODELE DE DONNEES (ENTITES JPA)
-------------------------------------

USER (utilisateurs)
  - id, nom, email (unique), password, role (VISITEUR/CLIENT/ADMIN)
  - Relation OneToMany avec Order

PRODUCT (produits / patisseries)
  - id, nom, description, prix, stock, deleted (soft delete), imageUrl
  - Relation ManyToOne avec Category
  - Validations : @NotBlank, @Positive, @Min(0)

CATEGORY (categories de produits)
  - id, nom, imageUrl

CART (panier)
  - id
  - Relation OneToOne avec User
  - Relation OneToMany avec CartItem

CART_ITEM (lignes de panier)
  - id, quantity
  - Relation ManyToOne avec Cart
  - Relation ManyToOne avec Product

ORDER (commande)
  - id, status (EN_COURS, VALIDEE, ANNULEE), createdAt
  - Relation ManyToOne avec User
  - Relation OneToMany avec OrderItem

ORDER_ITEM (lignes de commande)
  - id, quantity
  - Relation ManyToOne avec Order
  - Relation ManyToOne avec Product

1.5. SECURITE (SPRING SECURITY)
--------------------------------
Le systeme de securite est configure dans SecurityConfig.java :

- Authentification : formulaire de login personnalise (/login)
- Encodeur de mot de passe : BCryptPasswordEncoder
- Provider : DaoAuthenticationProvider avec CustomUserDetailsService
- Gestion des roles :
    * ROLE_ADMIN  -> acces complet aux routes /admin/**
    * ROLE_CLIENT -> acces aux routes /client/** et /cart/**
    * Visiteur    -> acces aux pages publiques

- Redirection apres login : selon le role
    * ADMIN  -> /admin/homeAdmin
    * CLIENT -> /client/homePatisserie

- Protections activees :
    * CSRF active par defaut (protection contre les attaques cross-site)
    * FrameOptions : SAMEORIGIN (protection clickjacking, compatible H2 Console)
    * Logout avec invalidation de session et suppression cookie JSESSIONID

- Mot de passe admin : externalise via variable d'environnement ADMIN_PASSWORD
  (plus aucun mot de passe en dur dans le code source)

1.6. FONCTIONNALITES METIER CLES
---------------------------------

A. Espace Public (non authentifie)
   - Consultation du catalogue de patisseries
   - Recherche de produits par mot-cle
   - Visualisation des details d'un produit
   - Inscription (register) avec validation du mot de passe

B. Espace Client (authentifie - ROLE_CLIENT)
   - Ajout de produits au panier avec verification du stock
   - Modification des quantites dans le panier
   - Suppression d'articles du panier
   - Passage de commande (creation Order + decrement stock)
   - Historique des commandes
   - Annulation de commande (restauration du stock)

C. Espace Administrateur (ROLE_ADMIN)
   - Tableau de bord admin
   - CRUD complet des produits (avec upload d'images)
   - CRUD complet des categories (avec upload d'images)
   - Gestion des commandes (liste, recherche par email, mise a jour statut)
   - Suppression logique (soft delete) des produits
   - Calcul du total des commandes

D. Gestion des fichiers (FileStorageService)
   - Upload d'images avec generation de noms uniques (UUID)
   - Validation du type MIME (image/*)
   - Whitelist d'extensions (.jpg, .jpeg, .png, .webp, .gif)
   - Protection contre le Path Traversal (Path.normalize() + startsWith)
   - Suppression securisee des fichiers
